# 3D Web Platform — Starter v0.1

## Quick start (Windows)
1. Install Node.js LTS from https://nodejs.org/
2. Extract ZIP.
3. Open the extracted folder (containing `package.json`).
4. Click File Explorer's address bar, type `cmd`, press Enter.
5. Run `npm install`, then `npm run dev`.
6. Open the local URL printed by Vite (usually http://localhost:5173/).

## Features
- Idea1: Interactive procedural robot, OrbitControls, material color / metalness / roughness.
- Idea2: Reserved tab, not yet implemented.

## Deployment
The `base` option in `vite.config.js` must be updated to your GitHub Pages repository path before deployment. Deployment is deliberately deferred until the local app is tested.
